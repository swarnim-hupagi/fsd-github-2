Bash Commands I Have Learned So Far

1. touch

File creation

The touch command creates a new, empty file. If the file already exists, it simply updates the file's last-modified timestamp instead of changing its content. It's one of the simplest ways to create a file directly from the terminal.

Syntax: touch filename

Example: touch notes.txt

Output:(no output - the file notes.txt is created silently in the current folder)

2. mkdir

Folder creation

The mkdir command creates a new, empty folder (directory) at the location you specify.

Syntax: mkdir foldername

Example: mkdir project

Output:(no output - the folder project is created in the current directory)

3. cd

Changing directory

The cd command changes the current working directory, moving you into a different folder in the terminal.

Syntax: cd foldername

Example: cd project

Output:(prompt changes to show that you are now inside the ~/project )

My understanding: grep searches through the contents of a file (or files) for lines that match a given word or pattern, and it prints out only the matching lines rather than the whole file. This makes it useful for quickly searching through a large file without having to open and read it manually.
